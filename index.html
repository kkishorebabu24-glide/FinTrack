      • HDFC Bank: PAN card in lowercase (or DOB in DDMMYYYY)
      • SBI / SBI Card: DOB (DDMM) + last 4 digits of registered mobile
      • ICICI Bank: DOB (DDMM) + last 4 digits of account/card
      • Axis Bank: First 4 letters of name (UPPERCASE) + last 4 digits of mobile/account
      ⚙️ Google Cloud API Configuration
      To sync directly with Google Drive and scan your Gmail inbox, you need your own Google Cloud OAuth 2.0 Web Client ID.
      ⚠️ Protocol Notice: You opened FinTrack via file:///. Google OAuth 2.0 strictly requires an http://localhost origin. To use direct Google Drive / Gmail Sync, run a local web server (e.g. npx serve or python -m http.server 8000), OR use the Quick Paste box below which works 100% offline without any API setup!
      Quick Setup Steps (Takes 2 minutes):
      1. Open Google Cloud Console → Credentials.
      2. Click Create Credentials → OAuth Client ID (Application type: Web application).
      3. Under Authorized JavaScript origins, add http://localhost:8000 (or your dev server port).
      4. Enable Google Drive API & Gmail API in the API Library.
      5. Paste the generated Client ID & API Key above.
